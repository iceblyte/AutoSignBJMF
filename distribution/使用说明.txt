班级魔方自动签到 · 使用说明
========================================

一、首次使用
------------
1. 双击 AutoSignBJMF.exe
2. 点「扫码添加 / 更新」，用微信扫窗口里的二维码（会自动填入 Cookie、姓名、班级）
3. 点「打开高德坐标拾取器」，在网页地图上选好位置，复制坐标，
   粘贴到弹出的输入框里（例如 39.9087,116.3975），点「保存」
4. 在「每天执行时间」里加你要的时间点，可以加多条（例如 07:30 和 21:31）
5. 点「启动后台运行」。之后关掉窗口 = 缩到右下角托盘，签到照常执行

二、数据存在哪
--------------
- 便携版（exe 旁边有 data 文件夹）：就近读写 data\ 目录，整个文件夹可以拷到 U 盘
- 单文件版（只有 exe）：写到 C:\Users\<你的用户名>\AutoSignBJMF\

  目录里有：
    data.json      账号、Cookie、经纬度、通知 Key
    settings.json  每天的时间点、重试设置
    logs\          运行日志

三、常见问题
------------
- 关掉窗口还在跑吗？
  在托盘里就还在跑。右键托盘图标可以「显示主窗口 / 立即签到 / 暂停 / 退出」。

- 关机或重启后会继续吗？
  不会自动继续。勾选界面右下角的「开机自启」，下次登录 Windows 时会自己起来。

- 电脑睡眠时到了签到点怎么办？
  睡眠期间不执行，醒来后会立刻补跑一次。想稳一点可以把电源计划改成「接通电源时永不睡眠」。

- Cookie 过期了（提示签到失败 / 姓名显示未找到）怎么办？
  点「扫码添加 / 更新」重新扫一次即可，其他配置不会丢。

- 签到失败了会重试吗？
  会。默认失败后重试 3 次、每次间隔 5 分钟，可以在界面上改。

- 数据安全
  data.json 里有登录凭证，不要发给别人，也不要连同 exe 一起分享。
