Web 管理端：表格为主，右侧详情常驻

管理端不重复实现配置表单，而是复用同一套字段组件在右侧抽屉里编辑 —— 这样坐标、时间点、通知 Key 的校验与文案与用户端、桌面端完全一致。 平台专属能力只有两个：管理员鉴权、批量操作。
