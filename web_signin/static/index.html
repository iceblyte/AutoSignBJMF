使用说明
1. 点「生成二维码」，用微信扫码，成功后姓名与班级会自动填入左侧表单。
2. 复制地图上的经纬度粘进「经纬度」，或点「坐标拾取」按浏览器定位。
3. 添加每天的执行时间，可加多条；提交后由后端按时间触发，与页面是否打开无关。
4. Cookie 只保存在服务端，页面不展示完整凭证；过期后重新扫码即可。
